Validation and rollout for the review fixes

This branch addresses review items 18 through 25, plus API integration for review 16. Account/server-scoped protected caches are cleared on logout. Sessions are shared through an expanded Keychain access group with fail-closed JWT expiry. Upload multipart bodies are streamed to protected files; background URLSessions and per-record coordinated upload state carry idempotency keys plus account/server identity. Logout cancels both upload sessions before deleting private state. Recording uses explicit states and recoverable drafts. Polling respects view lifetime and active scene. Initial upload includes manual class selection. Offline summaries no longer overwrite richer note details, deletion reconciliation uses complete paginated lists, and actual transcripts are cached. Note/transcript correction, per-note share management, Markdown export and additional VoiceOver labels are included.

Swift was not built or run. There is no Xcode in the Linux sandbox. Run xcodegen to regenerate the project with Shared and Recording files, then compile with Xcode and validate Swift 6 concurrency, Clerk APIs, deployment target availability, background session delivery, account transitions and audio interruption behavior. Do not treat source inspection as an iOS build.

Both targets need group.com.kobosh.notes in their app groups, and $(AppIdentifierPrefix)group.com.kobosh.notes in keychain-access-groups. The KeychainAccessGroup Info.plist value must expand to the same full group. Confirm both signed provisioning profiles include it. Keychain failures are reported instead of silently ignored. Legacy plaintext extension tokens are cleared; opening Notes refreshes the Keychain token. Unknown token expiry is not accepted by the extension.

Deploy the web companion branch first. It provides paginated summary lists with X-Has-More, durable idempotent upload handling, multipart className/study preferences, owner transcript PATCH and title/content PATCH, and share create/revoke/rotate with expiry and chat consent. Back up and migrate web shortcut tokens and old processing jobs as documented in that repository. Neither migration was run here.

Review 25 is partial. Individual sharing and corrections are implemented; bulk sharing, multi-note chat, incoming shared-link routing and persistent native chat/study progress are not. The extension remembers the latest language but does not yet offer a complete picker. Follow those as separate features rather than considering full web/native parity finished.
